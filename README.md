# BuildAI Free Starter

A simple free/open-source starter for an AI website & app builder.

## Run
1. Install Node.js 18+
2. Run `npm install`
3. Run `npm run dev`
4. Open the local URL shown by Vite.

## Important
This starter includes a working UI, project/file management, preview simulation, ZIP export, and a pluggable AI endpoint.

For truly free AI generation, connect a locally hosted/open-source model (for example through Ollama) later. No paid API key is included.
